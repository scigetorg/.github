# Welcome to SciGet.org

Run scientific software anywhere. SciGet.org is an open-source platform for running containerised scientific tools on laptops, cloud infrastructure, and HPC systems. 

- **Get started:** [Install and use SciGet](https://sciget.org/get-started/).
- **Useful resources:** [How SciGet works](https://sciget.org/about/) and [the SciGet website](https://sciget.org/).
- **Join the community:** Ask questions and share ideas in [Discussions](https://github.com/orgs/scigetorg/discussions).
- **Contribute:** Explore the repositories below, report issues, or propose improvements through pull requests.
